# PDF Language Detector

## Project Overview
PDF Language Detector is a Python application that analyzes PDF files and identifies the languages used in their text.

The application extracts text from PDF files, detects the language, and displays a language distribution report with a visualization.

## Features
- Upload PDF files.
- Extract text from PDF documents.
- Detect the language of extracted text.
- Analyze language distribution.
- Display a visual report.

## Technologies Used
- Python
- PyMuPDF
- langid
- Gradio
- Matplotlib
- Pandas

## Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Open the project folder:

```bash
cd PDF-Language-Detector
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

## Usage
1. Run the application.
2. Upload a PDF file.
3. View the language analysis report.
4. Check the language distribution visualization.
